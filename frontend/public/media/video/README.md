# Videos locales (opcional)

Coloca aquí los MP4 con el **id** del video como nombre de archivo, por ejemplo:

```
30f4b3_e69e6e84feb449179324777b6af7861d.mp4
```

Los ids están en `backend/data/videos.json`. El backend detecta el archivo
automáticamente y el reproductor lo usa en lugar del enlace de YouTube o del
enlace al sitio original. No hace falta reiniciar el backend.

Los MP4 se pueden exportar desde el panel de Wix (Video Library → Descargar).
